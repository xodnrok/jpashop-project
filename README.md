# 📚 중고 도서 거래 플랫폼 (Toy Project)

## 1. 프로젝트 소개
* **Ref:** [인프런 김영한님 스프링 부트 활용 강의](https://www.inflearn.com/course/%EC%8A%A4%ED%94%84%EB%A7%81%EB%B6%80%ED%8A%B8-JPA-%ED%99%9C%EC%9A%A9-1/dashboard)
  
김영한님의 스프링 부트와 JPA 활용 강의를 기반으로 구현한 중고 도서 거래 서비스입니다. 
회원가입 및 로그인, 도서 등록, 주문·취소, 주문 내역 조회 기능을 구현했습니다. 
이후 별도로 학습한 Spring Data JPA와 QueryDSL를 적용해 기존 데이터 접근 로직 , jpql로 복잡합 동적검색 로직을 리팩토링했습니다.

## 2. 사용 기술 (Tech Stack)
* **Language:** Java 21
* **Framework:** Spring Boot 3.x
* **Data Access:** Spring Data JPA, QueryDSL
* **Database:** MySQL
* **View:** Thymeleaf
* **Utils:** Lombok, Validation

##2. 주요 기능

**회원 관리 및 인증**

*회원가입 및 아이디 중복 검증

*세션 기반 로그인 및 로그아웃

*입력값 검증을 통한 필수 입력 항목 확인

*인터셉터를 활용한 회원 전용 URL 접근 제어

**도서 및 주문 관리**

*중고 도서 등록 및 등록 상품 목록 조회

*도서 주문 및 주문 취소

*주문 취소 시 주문 수량에 따른 재고 복구

*주문 내역 조회 및 상품명·주문 상태 기반 검색

**요청 추적 및 데이터 전달**

*인터셉터를 활용한 요청 URL 및 컨트롤러 동작 로그 기록

*DTO를 활용한 데이터 전달

##3. 기술적 개선 사항 (My Contribution)

강의에서 구현한 기본 기능을 바탕으로 별도로 학습한 기술을 적용하고, 데이터 접근 방식과 검색 기능을 확장했습니다.

**3.1 Spring Data JPA 적용**

*기존 JPA 기반 데이터 접근 방식을 Spring Data JPA 리포지토리 기반으로 확장

*반복적인 데이터 접근 코드의 작성 부담을 줄이고 데이터 처리 구조 개선

**3.2 QueryDSL을 활용한 동적 검색**

*주문 상태와 상품명에 따른 검색 조건 구현

*검색 조건에 따라 쿼리를 동적으로 구성

*문자열 중심의 쿼리 작성 방식에서 벗어나 타입 안전성을 고려한 검색 로직 구성

**3.3 데이터베이스 변경**

*H2에서 MySQL로 데이터베이스 변경

*MySQL 기반으로 데이터 저장 및 조회 환경 구성

**3.4 도메인 확장**

*기존 Item 엔티티에 UsedPrice 관련 필드를 추가하여 중고 도서 거래에 필요한 가격 정보 반영

**3.5 접근 제어 및 응답 데이터 개선**

*인증 인터셉터를 통해 비회원의 회원 전용 URL 접근을 제한

*API 응답에 DTO를 활용하여 엔티티의 직접 노출을 줄이고 필요한 데이터만 전달

*요청 URL 및 관련 컨트롤러 정보를 기록하여 요청 흐름을 추적할 수 있도록 구성

## 4. 프로젝트 회고 (Retrospective)
개별 기술을 학습하는 것과 여러 기술을 하나의 프로젝트에 통합하는 과정은 다르다는 점을 경험했습니다. 기능을 통합하면서 발생한 다양한 오류를 해결하기 위해 코드를 디버깅하고, AI와 개발자 커뮤니티를 참고하며 원인을 분석했습니다.

특히 강의에서 학습한 JPA 기반 구현을 바탕으로 Spring Data JPA와 QueryDSL을 추가 적용하면서 데이터 접근 방식과 동적 검색 기능을 확장할 수 있었습니다. 이를 통해 단순히 기술의 사용법을 익히는 데 그치지 않고, 각 기술이 필요한 이유와 프로젝트 내에서의 활용 방식을 이해하는 경험을 쌓았습니다.
