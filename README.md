# 📚 중고 도서 거래 플랫폼 (Toy Project)

## 1. 프로젝트 소개
* **Ref:** [인프런 김영한님 스프링 부트 활용 강의](https://www.inflearn.com/course/%EC%8A%A4%ED%94%84%EB%A7%81%EB%B6%80%ED%8A%B8-JPA-%ED%99%9C%EC%9A%A9-1/dashboard)
인프런 김영한님의 스프링 부트 로드맵 강의를 기반으로 핵심 기술을 학습하고, 실제 서비스를 개발해보는 프로젝트입니다.
강의의 기본 코드를 단순 클론 코딩하는 것을 넘어, **인증/인가, 동시성 제어, 동적 쿼리 개선** 등 실무적인 요소를 추가하여 재설계하였습니다.

## 2. 사용 기술 (Tech Stack)
* **Language:** Java 21
* **Framework:** Spring Boot 3.x
* **Data Access:** Spring Data JPA, QueryDSL
* **Database:** MySQL
* **View:** Thymeleaf
* **Utils:** Lombok, Validation

## 3. 강의와 차별화된 점 (My Contribution) 
단순 학습용 코드를 **생산적이고 유지보수 가능한 코드**로 개선하기 위해 다음과 같은 기술을 도입했습니다.

###  기술적 고도화
* **Spring Data JPA 도입:** 순수 JPA 기반의 반복적인 CRUD 코드를 Spring Data JPA로 리팩토링하여 생산성 향상.
* **QueryDSL 적용:** 문자열 기반 JPQL의 오타 문제와 동적 쿼리 작성의 어려움을 해결하기 위해, 타입 안전성(Type Safety)이 보장되는 QueryDSL 도입.
* **DB 교체 (H2 → MySQL):** 인메모리 DB 대신 실무 환경에 적합한 MySQL을 사용하여 데이터 영속성 확보.

###  기능 확장 및 문제 해결
* **동시성 제어 (Concurrency Control):**
    * 주문 시 재고 차감 로직에 **JPA 낙관적 락(`@Version`)**을 적용.
    * 충돌 빈도가 낮을 것으로 가정하여, 비관적 락(DB Lock) 대신 애플리케이션 레벨의 버전을 체크하는 방식을 선택해 성능 저하 최소화.
* **도메인 확장:**
    * 기존 `Item` 엔티티에 `UsedPrice`(중고가) 필드를 추가하여 중고 거래 비즈니스 로직 구체화.
* **검색 및 조회 기능 개선:**
    * 주문 상태(OrderState) 및 상품명 기반 검색 기능 추가.
    * 로그인 세션 정보를 활용하여 **"내 주문 내역"**만 조회되도록 개인화 로직 구현.

###  보안 및 로그 (Security & Logging)
* **인증 인터셉터(Interceptor):** 비회원이 회원 전용 URL에 접근 시 로그인 페이지로 리다이렉트 처리.
* **로깅 시스템:** 사용자의 접속 URL 및 호출된 컨트롤러 정보를 로그로 남겨 트래킹 환경 구축.
* **세션 기반 로그인:** HttpSession을 활용한 로그인/로그아웃 기능 구현.
* **DTO(Data Transfer Object) 패턴 적용:** 클라이언트와 통신시 엔티티 대신 DTO를 사용해서 내부 도메인 모델의 구조 캡슐화 , 불필요한 정보 노출을 막고 필요한 정보만 전달

## 4. 프로젝트 회고 (Retrospective)
개별 기능 단위로 학습할 때는 보이지 않았던 **기술 간의 의존성과 통합 시 발생하는 복잡함**을 직접 경험할 수 있었습니다.
단순히 강의를 듣는 수동적인 학습에서 벗어나, 흩어진 기술들을 하나의 시스템으로 조립하는 과정에서 수많은 에러를 만났습니다. 하지만 이를 직접 디버깅하고 해결하는 과정에서 왜 이 기술이 필요한지를 깊이 이해하게 되었고, 단순 암기가 아닌 저만의 지식으로 만들 수 있었습니다.
또한, 문제 해결을 위해 커뮤니티를 탐색하면서 추가적인 정보도 더 얻을수 있는 좋은 경험이였습니다.
